# React Frontend UI Project

A modern responsive React frontend project built using React.js and CSS.

## Features

* Responsive Hero Section
* Auto Sliding Banner
* Blur Background Effects
* Marquee Image Animation
* Product Cards Section
* Interactive Buttons
* Responsive Design for Mobile & Tablet
* Smooth UI Animations

## Technologies Used

* React.js
* CSS3
* JavaScript
* Vite
